# Aurora Omarchy password switch

This optional companion supplies the Omarchy dialog and the in-process Qt D-Bus bridge for fprintd-aurora's experimental password-switch protocol. The bridge uses the same process as the polkit agent, as required by the PAM module's sender check. It targets Omarchy's Quickshell plugin API; it is not a replacement for GNOME or KDE agents.

**Enable only when every polkit request on the system is handled by this compatible agent.** PAM configuration is shared across users and sessions. Stock agents display the token; there is no capability negotiation. Package installation alone does not change PAM or any user's shell configuration.

For the Omarchy user, copy `/usr/share/aurora-omarchy-polkit/plugin` to `~/.config/omarchy/plugins/aurora.polkit` and enable `aurora.polkit` through Omarchy's plugin manager. It replaces `omarchy.polkit` as its clone. Do not overwrite an existing user plugin. Confirm that the agent is active and no incompatible agent can serve another session. Then run `pkexec /usr/bin/aurora-polkit-pam --enable`. This appends `polkit-password-switch` only to a single existing fingerprint auth line in `/etc/pam.d/polkit-1`; it does not create or change the rest of the password stack. If the file was managed by aurora-sep, its ownership checksum is kept in sync.

To turn it off, run `pkexec /usr/bin/aurora-polkit-pam --disable` before disabling or replacing the companion agent, then disable/remove the user plugin and restore the original agent. The tool removes only the exact option-bearing line it created, preserving unrelated file edits; if that line has been changed it stops and asks for manual resolution. It updates aurora-sep's checksum only if the file still matches aurora-sep's recorded checksum. Other edits are treated as administrator-owned.

The package depends on `fprintd-aurora>=1.94.5-5`, so normal pacman transactions refuse an incompatible downgrade while the companion remains installed. A pre-transaction hook also disables the PAM option before either package is upgraded or removed, including a forced fprintd downgrade. Re-enable explicitly after an upgrade only after checking that the compatible agent is still active. If the managed PAM line was edited, the hook aborts the transaction to avoid leaving an unknown configuration behind. The per-user plugin is not deleted automatically; with the option disabled it no longer offers the button and can be removed by its owner.
